# 電撃パチンコ・ビンゴ // NEON BINGO CRASHER

**2Dパチンコ物理（480Hzサブステップ） × 5×5ビンゴ役づくり × ローグライト倍率インフレ**を組み合わせたサイバー・アーケードゲームです。PC（横ワイド筐体）とスマートフォン（縦持ちゼロスクロール）の双方に完全対応しています。

## ゲームの特徴

- **パチンコ物理 × 狙い撃ちストローク**
  - 左外周の発射シュートからドーム天井へ玉を打ち出し、パワー（0%〜100%）および4段階ルートプリセット（**左打ち / ぶっ込み / 中央 / 右打ち**）で狙う列（B・I・N・G・O）をコントロールできます。
  - `固定連射 (LOCK)` や発射ボタン長押しによる小気味よい連射に対応。
- **5列ポケット直結・5×5ネオンビンゴ & OVERDRIVE覚醒**
  - 玉が B・I・N・G・O ポケットに入ると、真下の列へレーザーが走りビンゴマスを開放（ビンゴ確定マスやリーチ形成マスを優先ロックオン）。
  - 同じ列の5マスがすべて開くとポケットが **【OVERDRIVE】** に覚醒！以降その列に入るたびにステージ倍率が乗算増幅し、他列へ電撃が飛び火します。
- **壊れコンボを生む3軸デッキ＆盤面改造（TUNING PARLOR）**
  - **特殊釘カスタム（6種）**: 玉が3つに増える `三連プリズム釘`、玉を爆弾化する `爆縮イグナイタ`、通過で倍率×1.4の `倍率スピナー`、リーチ列へ引き寄せる `リーチ誘導コア` などを盤面の好きなカスタムスロットへ装着・付け替え可能（おまかせ最適配置にも対応）。
  - **特殊ボール（5種）**: 周囲5マス（強化時3×3の9マス）を一挙爆破＆再点火する `ボム球`、初撃2分裂の `ミラージュ球`、列全体を縦貫通する `レーザー貫通球`、資金＆2連OVERDRIVEの `ジャックポット金球`。
  - **レリック（全12種・最大6枠）**: 既開放マス再ヒットごとにステージ倍率が乗算される `再点火コンデンサ`、ボムを3×3化する `連鎖爆縮炉`、8バウンスごとに雷撃開放する `ハイボルテージ釘師` など。
- **FULL BINGO FEVER & エンドレスモード**
  - 25マス全開放で **FULL BINGO FEVER** 突入！ボーナス球補充＋カードレベル上昇＋**ステージ倍率を引き継いだまま新カードへ更新**され、全8ステージ突破後は無限インフレの **ENDLESS MODE** へ突入できます。

## 起動・ビルド・検証コマンド

```bash
pnpm install
pnpm run dev        # 開発サーバー起動 (http://localhost:5173)
pnpm test           # Vitest 物理・倍率・状態遷移ユニットテスト (11項目)
pnpm run build      # TypeScript型検証 + Vite本番ビルド
pnpm run test:e2e   # Playwright PC/スマホ実機描画・非重複・エラー検証
```
